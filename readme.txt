Snail Run (IS1200 MINI PROJECT OCTOBER 2025)

Game developed for the DE10-Lite (DTEK-V) board.
The game is written in C and runs directly on the on-board RISC-V processor.

How to compile and run:
- Extract all files into a folder
- Navigate to directory containing the files
- Compile using the command "make" to terminal
- Run using the command "dtekv-run main.bin"

Inputs and Outputs:
- Renders graphics to VGA display
- Outputs score to 7 segment display
- Flick SW0 to move upwards
- Flick SW1 to move downwards
- Press KEY1 to reset the game when game is over
- Press KEY0 to reset the board
